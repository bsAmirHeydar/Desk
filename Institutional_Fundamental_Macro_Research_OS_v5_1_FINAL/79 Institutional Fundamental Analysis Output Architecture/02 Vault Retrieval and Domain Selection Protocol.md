# Vault Retrieval and Domain Selection Protocol

## Goal

Retrieve the smallest set of notes that is sufficient for a complete answer, while preserving every material domain and rival explanation.

## Retrieval layers

1. **Object layer:** asset, company, country, commodity, event or portfolio MOC.
2. **State layer:** growth, inflation, labor, fiscal, monetary, credit, liquidity and physical systems.
3. **Pricing layer:** expectations, curve, valuation, carry, risk premium and implied distribution.
4. **Transmission layer:** rates, FX, credit, cash flow, balance sheet, funding, supply chain and positioning.
5. **Institution layer:** central bank, treasury, regulator, exchange, industry structure and political system.
6. **Historical layer:** comparable regimes and point-in-time cases.
7. **Control layer:** sources, contradictions, unknowns, model cards and horizon rules.

## Relevance test

A note is included only if it changes state estimation, expectation estimation, valuation, transmission, scenario probability, tail loss, confidence or invalidation. Background material that does not affect the object is excluded from the final synthesis.

## Retrieval evidence

The analysis record lists the MOCs, driver books, model notes, country books, cases and source contracts used. This creates an audit trail between the query and the canon.

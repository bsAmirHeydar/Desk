# Multihorizon State Synthesis Matrix

## Horizons

| Horizon | Typical object | Required distinction |
|---|---|---|
| Structural | institutions, demographics, technology, resource system | slow constraints and long-run distributions |
| Cyclical | growth, inflation, labor, credit, profits | state and transition over months or quarters |
| Tactical | policy repricing, issuance, earnings revisions, positioning | weeks to months |
| Multi-day | catalyst sequence, persistent repricing, physical imbalance | several sessions |
| Day-horizon | overnight changes, scheduled events, funding and flow conditions | current session or day |
| Event | surprise, reaction function and immediate transmission | minutes to sessions |
| Market formation | liquidity, basis, hedging, auction and balance-sheet constraints | intraday mechanism, not chart analysis |

## Inheritance

Higher horizons define priors and constraints; lower horizons update them only when evidence has sufficient persistence and mechanism. No horizon may erase another without a stated transition rule.

## Conflict matrix

Every analysis states:

- aligned horizons;
- conflicting horizons;
- estimated half-life of each conflict;
- which conclusion applies to which horizon;
- which evidence could promote a short-horizon shock into a regime transition.

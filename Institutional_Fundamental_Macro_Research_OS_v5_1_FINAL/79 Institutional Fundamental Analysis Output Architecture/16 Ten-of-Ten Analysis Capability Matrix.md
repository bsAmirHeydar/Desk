# Ten-of-Ten Analysis Capability Matrix

| Capability | 10/10 evidence |
|---|---|
| Current market analysis | Complete state, pricing, transmission, cross-asset, scenarios, horizons, unknowns and source ledger. |
| Historical reconstruction | Frozen information set, vintages, contemporaneous expectations and strict ex-post separation. |
| Asset analysis | Instrument-specific payoff, valuation, financing, institutional structure and regime behavior. |
| Country analysis | Institutions, accounts, policy, balance sheets, external vulnerability and market transmission. |
| Corporate analysis | Statements, business economics, competitive structure, expectations, valuation and scenarios. |
| Commodity analysis | Physical location-time-quality balance, logistics, curves, policy and financial transmission. |
| Event analysis | Priced baseline, surprise vector, reaction function, leaders, persistence and alternative interpretation. |
| Portfolio analysis | Hidden factors, nonlinear exposure, liquidity, scenario loss, hedge failure and update triggers. |
| Cross-asset synthesis | Mechanism-based confirmation and contradiction without double counting. |
| Source and evidence | Claim-level locators, vintages, limitations and contradiction records. |

## Promotion rule

The Vault cannot be called 10/10 until all capability rows are supported across all material domains and the residual frontier is explicitly bounded.

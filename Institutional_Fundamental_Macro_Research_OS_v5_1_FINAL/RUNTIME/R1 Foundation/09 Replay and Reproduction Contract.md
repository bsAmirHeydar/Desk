# Replay and Reproduction Contract

## Historical replay

A historical replay is an ordinary Universal Run with a historical `analysis_cutoff`. It must use point-in-time visibility rules and the same downstream scientific runtime as live work once R2 is installed.

## Reproduction replay

A reproduction replay pins a prior run's:

- analysis cutoff;
- snapshot manifest;
- Vault stack/commit;
- Runtime version;
- future prompt pack/model profiles when available;
- schema versions.

R1 can reproduce the **evidence visibility world**. Full cognitive decision reproduction is activated in R2 when the prompt process graph exists.

## Parity target

Given identical admissible snapshots and identical version pins:

```text
LIVE-LIKE VISIBILITY RECEIPT
==
REPRODUCTION VISIBILITY RECEIPT
```

If later stochastic model output differs, future R2/R4 must issue a reproduction-variance receipt rather than silently claiming bitwise determinism.

## No shortcut backtest

Bulk replay is not permitted to bypass per-run point-in-time evidence admission. Caching may reuse identical immutable artifacts but may not bypass visibility checks.

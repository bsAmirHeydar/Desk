# Source Failure, Revision and Licensed-Gap Certification

R4 certifies semantics rather than pretending all sources are available.

- registered source != connected source;
- licensed/private source != available source;
- proxy != direct fact;
- missing direct evidence stays a gap even if contextual proxy data exist;
- historical current-only data are forbidden;
- official vintage archives are admissible according to R1 rules;
- temporary source failure cannot be silently converted to zero/neutral;
- decision-critical gaps constrain completion.

Environment certification records which production bindings are actually active. Offline certification never claims that a paid/private feed is connected.

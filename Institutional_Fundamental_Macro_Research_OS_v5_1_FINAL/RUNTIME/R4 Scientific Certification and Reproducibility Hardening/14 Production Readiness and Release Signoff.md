# Production Readiness and Release Signoff

`PRODUCTION_READY` is an explicit governance state, not a software-generated adjective.

Required evidence:
- CORE_CERTIFIED;
- FULL_OFFLINE_CERTIFIED;
- ENVIRONMENT_CERTIFIED;
- SHADOW_PRODUCTION_CERTIFIED;
- no unresolved decision-critical certification finding;
- exact release fingerprints for scientific stack, runtime, Prompt Pack and provider/model bindings;
- rollback tested;
- operator understands remaining private/licensed source gaps;
- direction authority remains `FUNDAMENTAL_ONLY`;
- runtime operational authority remains `BLOCK_ONLY`;
- no automatic D4 promotion authority exists.

Sign-off certifies the deployed runtime boundary. It never guarantees market profits or future forecast accuracy.

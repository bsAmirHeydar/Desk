# Counterfactual Engine and Frozen Alternatives

Counterfactuals are defined from the frozen decision information set, not selected after seeing the outcome. Supported scientific branches follow D4: PRE_D3_BASELINE, V19_D3_BASELINE, REMOVE_MODIFIER, POSITIVE_PROMOTION_SHADOW and DELAY_ALTERNATIVE.

Every branch must use the same execution profile and frozen information set. Ex-post entry optimization is forbidden. If a hypothetical branch cannot be deterministically scored, its state is UNSCORABLE rather than estimated.

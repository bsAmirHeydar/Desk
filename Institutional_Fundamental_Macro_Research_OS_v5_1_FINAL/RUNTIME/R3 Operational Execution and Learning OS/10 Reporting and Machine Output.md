# Reporting and Machine Output

R3 produces deterministic machine JSON and a human Markdown report from frozen typed artifacts. Report depth may be MACHINE, COMPACT or FULL; analytical completeness is not tied to prose length.

Every report must expose run id, cutoff, decision seal, permission, validity/recheck/invalidation, fundamental direction, edge state and material evidence gaps. Numeric probability is forbidden unless supported by a valid D4 calibration record.

# Adaptive Escalation and Depth

Default research depth is AUTO. Escalation is targeted when the system observes a decision-material causal contest, high unmodeled-driver risk, material data gap, cross-asset inconsistency, driver transition, event shock or crisis/dislocation.

`EVENT_FAST_STRICT` changes priority, not standards. `DEEP_ESCALATION` adds only the missing scientific dependencies. The synthesis loop is capped at two iterations to avoid endless reasoning.

# Epistemic Completion Gate

R2 stops when the decision is **epistemically complete**, not when a token budget is exhausted. Decision-critical questions must be resolved or explicitly unresolved with a fail-closed constraint; material gaps must be disclosed; rival hypotheses searched; a material adverse path considered; triggers structured; D3 and D4 authority resolved.

More prose is not more completeness. Quiet runs may be compact; contested/event/crisis runs escalate depth.

# Full-Vault Strict Context Compiler

`FULL_VAULT_STRICT` does **not** mean blindly loading every file. It means every canonical authority, material fact family and causal dependency is accounted for. The context compiler activates the smallest sufficient canonical set from the manifest, asset books, required runtime contracts, topic-aware retrieval dependencies and process-specific dependencies. Every excluded material dimension requires a reason.

Outcome/future artifacts are structurally forbidden before Decision Seal.

# Prompt Execution Constitution

R2 separates **evidence truth rules** from **interpretive flexibility**. Fact identity, point-in-time visibility, lineage, schema integrity, authority and no-lookahead are strict. Hypothesis count, scenario count, model pluralism, materiality and research depth remain context-sensitive.

No process receives free conversation memory. Every process receives a typed Context Bundle whose artifacts, canonical Vault dependencies and forbidden inputs are recorded and hashed.

No process may create authority outside its manifest. Only `W31_FUNDAMENTAL` may create Fundamental Direction; only `P63_FINAL_DECISION` may create the research BUY/SELL/NO_TRADE adapter; R3 still owns broker/operational execution gating.

# Method Receipts, Exceptions and Quarantine

Each governed run can carry a META-world method plan and phase receipts. Exceptions must name the default rule, relaxed rule, reason, scope, expected risk and review condition. Hard invariants may not be relaxed by an exception in M1.

Quarantine is reversible and explicit. It blocks scientific sealing when a hard methodological breach is confirmed; it does not delete artifacts and does not create a substitute market decision.

# Adaptive Protocol Router

The router implements constitutional pluralism. One invariant core governs multiple explicit protocols: descriptive/state estimation, events, causal attribution, direction, persistence/reversal, narrative/attention, regime, structural thesis, relative value, exposure/risk, model validation, anomaly/failure investigation and new-asset research.

Routing is auditable. Explicit `research_class:` or `method_class:` tags override heuristic routing. Otherwise event coverage/tags and problem tags are used, with existing Alpha Lab production runs defaulting to `DIRECTIONAL_FORECAST`. Rigor can be LIGHT, STANDARD, DEEP or CRITICAL without weakening hard invariants.

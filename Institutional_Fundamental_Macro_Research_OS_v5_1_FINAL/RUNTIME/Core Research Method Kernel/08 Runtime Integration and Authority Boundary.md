# Runtime Integration and Authority Boundary

M1 hooks into R2 at four points: bootstrap planning, post-lineage evidence validation, post-adversarial cognition validation, and pre-decision validation. R4 includes M1 preflight as an inherited certification component.

M1 has **no fact, direction, permission, broker-write or scientific-mutation authority**. Valid runs retain Decision World and Decision Seal parity because M1 writes only META artifacts and does not add lifecycle events. A confirmed hard method violation can stop the run before sealing.

APL-A remains a post-seal read-only shadow layer. APL-B remains absent.

# APL-A — Alpha Perspective Layer

Status: `APL-A 1.0.0` — `SHADOW_ONLY`

APL-A is a post-science perspective layer. It cannot create or edit facts, cannot create or flip fundamental direction, cannot create BUY/SELL/NO_TRADE, and cannot retrieve external data. It runs as a shadow observer over a frozen pre-decision information set after the R1 decision seal so that production permission is mechanically non-interfered with.

The source Talebian vault remains independent and read-only. APL-A compiles a provenance-preserving Alpha-facing canon rather than copying the source vault wholesale.

**Law:** DATA FIRST → SCIENCE SECOND → PERSPECTIVE THIRD.

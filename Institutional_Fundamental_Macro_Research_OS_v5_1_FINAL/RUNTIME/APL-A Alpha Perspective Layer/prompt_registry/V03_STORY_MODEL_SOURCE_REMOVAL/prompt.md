# V03 — Story / Model / Source Removal

Perform counterfactual analytical isolation only; never delete or mutate upstream artifacts. STORY REMOVAL strips explanatory narrative while retaining admitted facts and causal structure. MODEL REMOVAL removes one materially load-bearing model/hypothesis/model class at a time. SOURCE REMOVAL removes one materially load-bearing independent source/root at a time using existing Alpha lineage semantics. Record baseline conclusion, removed object, surviving evidence, changed/unchanged conclusions, fragile/robust dependencies, decision-sensitive dependence and invariant candidates. The test is not allowed to invent replacement evidence.

## Absolute authority boundaries
- No fact creation or reclassification.
- No fundamental direction creation/flip.
- No BUY/SELL/NO_TRADE creation.
- No web or outside knowledge as evidence.
- No outcome/future/P63 permission context.
- Preserve uncertainty and provenance.
- Return only artifacts required by the supplied schemas.

# Shadow Production Certification

Shadow certification is an operational test, not a profitability test.

After environment certification, C1 can run all six production instruments through the complete `SHADOW_LIVE + STRICT_FULL + DEEP` path. Every component must reach a valid Decision Seal without authority, lookahead, prompt/context drift, host, or retrieval-contract failure.

The receipt records material and decision-critical evidence gaps. A system may be operationally shadow-certified while still disclosing source insufficiency; production-readiness for permission delivery remains separately gated.

Shadow mode never emits a broker order and uses `SHADOW_ONLY_V1`.

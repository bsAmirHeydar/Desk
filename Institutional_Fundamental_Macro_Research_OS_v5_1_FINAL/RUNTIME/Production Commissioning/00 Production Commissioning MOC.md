`Human intent -> AlphaLab.ps1 -> R3 launcher -> strict pre-cutoff retrieval -> R1 run/time/store -> R2 prompt graph -> OpenAI host -> P63 -> Decision Seal -> permission-only handoff/report.`

- Direction authority remains `FUNDAMENTAL_ONLY` through W31.
- Final scientific permission remains P63 only.
- C1 operational authority is `NONE`; R3 remains `BLOCK_ONLY`.
- No broker/order-write capability is introduced.
- Model cognition gets no web tool. Only the retrieval role may use web search.
- No silent model downgrade. The default commissioned binding is GPT-5.6 Sol; actual returned model identity is recorded in receipts.
- No silent context truncation. Oversized context fails closed.
- Full-Vault means governed, dynamic, hash-pinned canonical context, not blind whole-vault loading.
- Public, licensed, private, unavailable, proxy and discovery evidence remain semantically distinct.
- Live cutoff is frozen only after strict pre-run intake completes.
- Historical current-only evidence is inadmissible.
- Environment and shadow certification are runtime attestations stored outside Git; installation alone cannot fabricate them.

# RUN2 Scientific Quality Gate and Run Memory

RUN2.0.0 makes per-run scientific quality and memory mandatory. `run <subject>` still remains the only normal user command.

Canonical order: Pre-Run → Evidence Plan/QA → 8 Clusters → M1 → Reconciliation → Hypotheses/Causal/Scenarios → Thesis Destroyer/Model Disagreement/Pre-Mortem → Direction/Decision → Force Lifecycle → APL-A Shadow → Final Readiness → Run Capsule → UI2.

Quality is multidimensional and never collapsed into a score. UNKNOWN and NO_TRADE remain valid outcomes. Run memory is mutable scientific evidence under AlphaLab_Data and stays outside R4/Git source fingerprints. Chat-native Runs produce portable capsules instead of pretending to mutate the uploaded Vault.

# Alpha Desk Unified Research Interface

## Canonical human command

`run <subject>`

For Chat-native use, the root `RUN.md` is the canonical one-command contract. LIVE mode, current time, deep internal analysis, method routing, scientific prompt/runtime orchestration, shadow fragility perspective, current evidence retrieval, mandatory quality gates, run memory and **UX3 Research Experience** are automatic.

## Canonical internal path

User command → Run Contract / Request Compiler → Method Governance → Scientific Prompt Graph → Scientific Runtime → Canonical Scientific Result → Decision → Shadow Perspective → Report Model → **UX3 Human Research Experience**.

The human interface has zero Direction/permission authority. The perspective layer remains shadow-only. The user-facing HTML does not expose Vault/runtime engineering. It communicates market output, uncertainty, scenarios, evidence meaning, high-level thinking guidance and limitations.

## Canonical UX3 experience

Command Center → Market Workspace → Analytical Lens → Single Deep-Dive Drawer.

For six-market runs, the first viewport must show all six markets, the common driver/opposition and the next material review/event. Only one market workspace is fully expanded at a time. Hourly use prioritizes `از یک ساعت قبل چه تغییر کرده؟` over repeated unchanged prose.

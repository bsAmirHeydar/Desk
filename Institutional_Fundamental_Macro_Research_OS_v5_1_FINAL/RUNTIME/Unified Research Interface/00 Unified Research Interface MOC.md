# Alpha Lab Unified Research Interface

## Canonical human command

`run <subject>`

For Chat-native use, the root `RUN.md` is the canonical one-command contract. The user only supplies the subject; LIVE mode, current time, deep internal analysis, M1 method routing, R2/R3 science, APL-A shadow perspective, current evidence retrieval and UI2 three-layer Persian reporting are automatic.

## Canonical internal path

User command → Run Contract / Request Compiler → M1 → R2 Prompt Graph → R3 Runtime → Canonical Scientific Result → existing Decision → APL-A Shadow → Report Model → UI2 Views.

The interface has zero Direction/permission authority. APL-A remains SHADOW_ONLY. Production certification remains a runtime receipt property. Chat-native manual research does not require the user's local API key or Windows environment certification.

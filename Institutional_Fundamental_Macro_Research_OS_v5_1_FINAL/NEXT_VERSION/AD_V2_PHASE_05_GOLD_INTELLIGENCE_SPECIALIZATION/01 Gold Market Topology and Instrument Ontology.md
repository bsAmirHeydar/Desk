# Gold Market Topology and Instrument Ontology

## Non-identity law

`XAUUSD != GC != GLD/ETF != London OTC != COMEX inventory != Asia physical != global Gold`.

Each is a market slice with different participants, clocks, financing, settlement and observability.

## Instrument roles

- **XAUUSD target** — target-price response for P03; never an independent P02 root or P04 release confirmation.
- **GC futures price** — mechanically linked target proxy and listed-market price-discovery diagnostic; not an independent Gold-direction vote.
- **GC trades / MBO / depth** — listed-market transaction/liquidity evidence when directly observed; cannot identify institutions by itself.
- **GC volume** — activity, not signed flow.
- **GC open interest** — outstanding contracts, not a directional long/short flow label.
- **Gold options** — volatility/path/mechanics evidence; open interest alone is not dealer gamma sign.
- **Silver** — precious-metals cross-asset diagnostic with independent industrial drivers; not a Gold Pressure root by default.
- **DXY / USD** — causal pathway state; top-level root only under an explicit autonomous USD mechanism, otherwise dependent on policy/risk roots.
- **2Y / real yields / curve** — policy/discount pathway and potentially root evidence when causal ownership is explicit; never double counted with the same policy root.
- **Gold ETFs** — product-specific investment flow/ownership subset.
- **Official-sector demand** — structural/cyclical reserve-demand subset.
- **Regional physical premiums/imports** — location-specific physical-balance evidence, not global Gold demand by themselves.

P05 never infers total global Gold state from a single venue.

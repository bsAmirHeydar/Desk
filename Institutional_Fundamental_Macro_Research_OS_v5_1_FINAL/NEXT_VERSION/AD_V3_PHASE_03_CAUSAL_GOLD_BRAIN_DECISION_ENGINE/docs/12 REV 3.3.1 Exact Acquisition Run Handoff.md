# AD-V3-P03 REV 3.3.1 — Exact Acquisition Run Handoff

P03 no longer infers current observation membership from `coverage.generated_at_utc`. It consumes the exact `acquisition_run_id` certified by P02. A complete 192-observation current-run set is mandatory before reasoning starts. Missing or mismatched run observations fail closed with `P02_P03_OBSERVATION_HANDOFF_INCOMPLETE`. Pre-3.2.5 P02 stores retain a backward-compatible cutoff fallback, but production V3 is expected to use exact run binding.

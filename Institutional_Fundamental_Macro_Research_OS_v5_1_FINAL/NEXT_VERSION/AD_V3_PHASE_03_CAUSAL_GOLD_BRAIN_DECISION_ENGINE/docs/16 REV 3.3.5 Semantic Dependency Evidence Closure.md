# AD-V3-P03 REV 3.3.5 — Semantic Dependency Evidence Closure

Derived semantic facts may not be adjudicated from dependency names alone. The evidence packet now attaches the exact current and previous observations for each declared dependency, with horizon eligibility and exact acquisition-run binding.

The packet also exposes evidence diagnostics (current/previous equality, raw-snapshot equality, warnings, dependency completeness). These diagnostics are epistemic context only and never create Direction.

External semantic bundles are additionally blocked from bypassing current-horizon eligibility for CAUSAL_FUNDAMENTAL, REALIZED_TRANSACTION, or MECHANICAL_FORCED facts. Structural carry remains background-only and has no session Direction authority.

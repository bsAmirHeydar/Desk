# REV 3.3.2 — Stock / Impulse / Horizon Semantics

## Problem found in first complete live P03 run

The exact-run handoff was correct, but unchanged positive real yields were being re-fired every session as fresh bearish Direction. The same rows were then given STRUCTURAL persistence because their contracts were valid across structural horizons.

That confuses three distinct concepts:

1. **Stock/background bias** — the level of a driver, e.g. positive real yields are a Gold headwind.
2. **Impulse/directional pressure** — the marginal change, e.g. real yields rising or falling now.
3. **Persistence of the current signal** — how long the active impulse may remain relevant.

## Canonical rule

For MICRO / SHORT / SESSION / DAILY reasoning:

- unchanged positive real yield => bearish background bias, **no new bearish Direction**;
- unchanged negative real yield => bullish background bias, **no new bullish Direction**;
- positive and rising => bearish directional pressure;
- positive and falling => MIXED (bearish stock versus bullish impulse);
- negative and falling => bullish directional pressure;
- negative and rising => MIXED (bullish stock versus bearish impulse).

Static stock state may be reported as background bias but cannot re-fire a session signal every run.

## Persistence rule

Persistence is derived from the current signal type and requested reasoning horizon, not from the longest horizon in which a fact can ever matter. A session real-yield impulse therefore cannot become STRUCTURAL merely because real yields also matter structurally.

## Consumption rule

`expectations_repricing` requires an actual policy/rate impulse. Merely observing an unchanged real-yield level does not count as repricing.

# Portable Memory

P06 derives a compact memory object from the canonical V2 state.

It may include:
- Pressure headline/trend;
- Transmission state;
- Unreleased Pressure;
- Opposing-Move Maturity;
- Release Readiness/Lifecycle;
- Event reset state;
- missing-driver escalation;
- inherited trade permission;
- concise changes from the previous run.

Portable memory is a convenience layer. It cannot override the capsule or upstream science.

# Semantic Change Detection

P06 compares states by **owned scientific meaning**, not arbitrary JSON diff.

## Pressure transitions
- sign/class;
- trend/acceleration;
- remaining causal pressure;
- persistence;
- contradiction/confidence.

## Transmission transitions
- transmission state;
- efficiency class;
- counterfactual residual magnitude/state;
- pathway state;
- missing-driver escalation.

## Latent transitions
- unreleased pressure;
- opposing-move maturity;
- latent causal reserve;
- transmission inflection;
- release readiness;
- release lifecycle;
- research blockers.

## Gold specialization transitions
- event reset cap;
- missing-driver search requirement;
- material coverage gaps / observability deterioration.

A change in target price by itself is not a Pressure change.

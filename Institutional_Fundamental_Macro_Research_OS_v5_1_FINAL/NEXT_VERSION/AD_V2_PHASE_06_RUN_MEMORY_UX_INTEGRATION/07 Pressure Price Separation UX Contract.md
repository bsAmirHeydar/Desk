# Pressure / Price Separation UX

The P06 command center must never collapse the model back into one Bullish/Bearish label.

The top-level screen shows four separate blocks:
1. **Directional Pressure** — P02;
2. **Price Transmission** — P03;
3. **Latent / Release State** — P04;
4. **Gold Evidence / Coverage** — P05.

Execution permission is displayed separately and inherited from V1.

## Required UX sentences
- Price movement does not directly alter Pressure.
- A divergence may represent delayed transmission or a missing driver; liquidity/absorption is not asserted without independent evidence.
- Release Readiness is not Trade Permission.
- `UNKNOWN`, `UNDETERMINED`, `BLOCKED` and `NO_TRADE` remain valid outputs.

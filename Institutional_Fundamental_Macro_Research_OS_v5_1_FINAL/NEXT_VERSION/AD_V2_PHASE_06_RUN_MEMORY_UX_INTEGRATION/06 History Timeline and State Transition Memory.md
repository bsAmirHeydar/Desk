# History Timeline

Each persisted V2 run produces a compact timeline record.

The timeline is designed for questions such as:
- Did Pressure remain BUY_HIGH while Price Transmission deteriorated?
- When did Opposing Move transition ACTIVE → MATURE → EXHAUSTING?
- When did Release Readiness move WATCH → PRE_RELEASE → HIGH_READINESS?
- Did a new event reset cap readiness?
- Was the eventual expansion preceded by high unreleased pressure?

The timeline is descriptive. It is not yet an empirical edge model. P07/D4 owns calibration and promotion.

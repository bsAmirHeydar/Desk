# P06 Release Notes

P06 adds the first integrated V2 Gold run envelope, immutable capsule extension, append-only V2 history, semantic change detection, portable memory, optional run-store attachment and a Pressure/Transmission/Release-separated Gold Explorer.

V1 is not modified. P02-P05 authorities are not changed. Trade permission is inherited from the V1 base capsule. Deployment remains SHADOW_ONLY.

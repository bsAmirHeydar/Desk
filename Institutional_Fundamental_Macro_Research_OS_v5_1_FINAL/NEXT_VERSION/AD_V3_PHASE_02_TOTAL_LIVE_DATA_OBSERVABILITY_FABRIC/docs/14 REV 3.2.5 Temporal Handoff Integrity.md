# AD-V3-P02 REV 3.2.5 — Temporal Handoff Integrity

P02 now binds every fact observation to an explicit `acquisition_run_id`. The coverage receipt carries the same run id plus acquisition start, observation cutoff, and acquisition completion timestamps. The full observation set is persisted before the coverage receipt is published. P03 must consume the exact run id and must fail closed if the 192-observation handoff is incomplete. Receipt generation time is never used as a substitute for observation membership.

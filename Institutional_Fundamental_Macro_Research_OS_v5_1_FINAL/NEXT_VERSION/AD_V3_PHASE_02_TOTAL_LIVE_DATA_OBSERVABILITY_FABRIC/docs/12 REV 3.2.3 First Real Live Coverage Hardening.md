# AD-V3-P02 REV 3.2.3 — First Real Live Coverage Hardening

## Purpose

The first real Windows/network acquisition after REV 3.2.2 correctly attempted every planned mandatory source and failed closed with 19 blocking Gold facts. REV 3.2.3 hardens those observed retrieval paths without weakening the Coverage Gate, Direct/Proxy semantics, or P02's shadow-only authority boundary.

## Observed blocker families and remediation

### BLS 403 family

Affected facts: US_CPI, US_CORE_CPI, US_PPI, US_PAYROLLS, US_UNEMPLOYMENT, US_WAGES, US_JOLTS.

Remediation: replace 403-prone human web pages with one official BLS Public Data API POST batch. The batch preserves individual series mapping, raw JSON snapshot, request-body provenance, and reference period.

### Retail sales 403

Affected fact: US_RETAIL_SALES.

Remediation: use the Federal Reserve Bank of St. Louis public CSV republisher for Census RSAFS. This remains PUBLIC_PROXY / official republisher, never DIRECT Census acquisition.

### Forward inflation timeout

Affected fact: US_5Y5Y_FORWARD_INFLATION.

Remediation: derive the 5y5y forward inflation rate from already-observed Treasury 5Y and 10Y breakeven facts. This is MODEL_DERIVED with explicit dependency lineage.

### Federal Reserve H.10 parser ambiguity

Affected facts: FED_AFE_DOLLAR, FED_EME_DOLLAR.

Remediation: use dedicated H.10 daily AFE and EME index pages with a date/rate parser instead of the aggregate H.10 summary surface.

### CME 403 family

Affected facts: GC_FUTURES_PRICE, GC_OPEN_INTEREST, GC_CURVE_TERM_STRUCTURE, FED_POLICY_PATH_PRICING, COMEX_DELIVERY_NOTICES.

Remediation: use best-effort CME-hosted delayed web JSON endpoints for structured Gold/Fed-funds curves and official CME Daily Bulletin / Issues-and-Stops PDFs as static fallbacks. Static PDF fallback observations remain PUBLIC_PROXY unless a semantic PDF parser directly proves the requested estimand. No licensed real-time data claim is made.

### PBoC TLS failure

Affected fact: PBOC_POLICY_LIQUIDITY.

Remediation: retain PBoC as primary and add an official State Council English-news fallback. The fallback is an official-government proxy and does not silently inherit primary-PBoC directness.

### SGE TLS failure

Affected fact: SGE_WITHDRAWALS.

Remediation: retain SGE as primary and add a World Gold Council China-market update fallback that cites SGE. The fallback remains PUBLIC_PROXY and must preserve the referenced month.

### India affordability retrieval

Affected fact: INR_GOLD_AFFORDABILITY.

Remediation: use the official RBI mobile rates surface to obtain USD/INR. Because USD/INR alone is not the full local-gold-affordability state, the fact remains PUBLIC_PROXY and carries an explicit limitation warning.

## Admission rule unchanged

A fallback improves observability only when it is explicitly declared. It cannot:

- convert a proxy into a direct observation;
- close a private or paid gap;
- grant Direction authority to P02;
- grant trade permission;
- bypass a blocking Fact whose admissible source paths all fail.

P03 may start only with a non-BLOCKED P02 live coverage receipt.

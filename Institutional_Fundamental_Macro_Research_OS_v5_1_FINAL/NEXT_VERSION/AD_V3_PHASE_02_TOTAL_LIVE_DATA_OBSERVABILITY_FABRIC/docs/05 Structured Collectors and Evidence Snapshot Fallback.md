# Collectors

Structured collectors exist for Treasury nominal/real curves, NY Fed SOFR, Federal Reserve H.10 dollar indexes and CFTC disaggregated Gold positioning. Other public sources use explicit evidence-snapshot extraction until a field-level structured parser is promoted. Snapshot fallback is visible as text/proxy evidence and cannot masquerade as a parsed numeric series.

## REV 3.2.3 collectors

Structured collectors now include BLS API JSON, dedicated Fed H.10 daily-index HTML, FRED CSV latest, RBI INR HTML, WGC SGE-withdrawal proxy parsing, CME Gold delayed JSON and CME Fed-funds delayed JSON. Binary Daily Bulletin fallbacks remain PUBLIC_PROXY unless a semantic PDF parser proves the requested field.

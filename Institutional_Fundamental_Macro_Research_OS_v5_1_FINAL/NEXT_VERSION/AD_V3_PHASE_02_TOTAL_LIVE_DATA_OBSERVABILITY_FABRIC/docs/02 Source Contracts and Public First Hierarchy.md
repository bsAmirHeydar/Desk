# Source Contracts

The source registry defines publisher, canonical location, machine endpoint, format, access class, cadence, publication lag, backups, required environment, provenance and raw-snapshot policy. Primary official/public sources are preferred. Paid/private gaps remain explicit instead of being proxy-filled.

## REV 3.2.3 live-source hardening

Where official public HTML blocks automated retrieval, P02 prefers an official machine endpoint, official static publication, or explicitly-labelled official/industry proxy. BLS macro series are batched through the public API; dedicated H.10 daily pages replace the ambiguous H.10 summary parser; source-specific POST/headers/body are part of the Source Contract. A fallback never inherits DIRECT semantics unless it directly observes the intended estimand.

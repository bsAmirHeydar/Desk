# AD-V3-P02 — Total Live Data & Observability Fabric

P02 converts the 192-object P01 Gold knowledge universe into an executable acquisition contract. P02 is SHADOW_ONLY. It can retrieve, parse, time-stamp, persist and gate observations, but it cannot set Gold Direction or trade permission.

Core invariant: **source attempted ≠ fact observed**. Fetch, parse, vintage, directness and availability are separate states.

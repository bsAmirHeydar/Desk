# REV 3.2.6 — Fact-Specific Source Integrity

## Why

Live semantic-packet audit exposed two concrete contamination modes:

- `IAU_HOLDINGS_SHARES` could select a SPDR/GLD page even when the iShares
  source existed.
- `GC_VOLUME` could fall back to CFTC COT text, which is positioning data and
  can contain unrelated market rows. COT is not a GC volume source.

A global "direct beats proxy" ranking is intentionally **not** used because
source precedence can encode a safer specialized parser or policy boundary.
Selection integrity is fact-specific.

## Rules

1. `GLD_HOLDINGS_SHARES` is bound to `ETF_SPONSOR`.
2. `IAU_HOLDINGS_SHARES` is bound to `ETF_SPONSOR_IAU`.
3. `GC_VOLUME` may use CME Gold quotes/volume surfaces only.
4. CFTC COT cannot fill GC volume.
5. If fact-specific valid evidence is unavailable, UNKNOWN/degraded coverage is
   preferred to a semantically wrong fallback.

This revision does not grant Direction or trade Permission.

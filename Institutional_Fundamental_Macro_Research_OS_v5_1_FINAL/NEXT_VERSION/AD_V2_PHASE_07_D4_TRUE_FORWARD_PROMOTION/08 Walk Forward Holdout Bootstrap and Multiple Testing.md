# Validation statistics

P07 follows D4 governance principles:
- chronological splits;
- dependence-aware resampling by independent episode/trading day;
- holdout reporting;
- true-forward reporting separately;
- bootstrap uncertainty intervals where sample size permits;
- hypothesis-family and multiple-testing disclosure;
- regime breakdowns;
- tail-risk comparison.

A numerical point estimate without adequate independent episodes is descriptive only.

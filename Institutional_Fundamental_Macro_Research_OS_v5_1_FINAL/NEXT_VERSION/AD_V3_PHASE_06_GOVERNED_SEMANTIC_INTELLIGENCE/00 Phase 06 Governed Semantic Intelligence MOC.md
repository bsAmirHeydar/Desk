# AD-V3-P06 — Governed Semantic Intelligence

P06 closes the semantic interpretation gap without creating a second Gold brain. P03 emits evidence-bound semantic requests; P06 compiles isolated requests, invokes an already-commissioned stateless MODEL_PROCESS host when available, validates the response deterministically, and returns only a P03-compatible governed bundle. Unsupported or invalid semantic claims fall back to UNKNOWN/non-additive.

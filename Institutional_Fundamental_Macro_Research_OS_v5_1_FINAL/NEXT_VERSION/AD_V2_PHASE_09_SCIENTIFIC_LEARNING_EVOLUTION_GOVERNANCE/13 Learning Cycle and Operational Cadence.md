# Learning cycle

P09 is intentionally slower than P08. It analyzes mature outcomes and does not need five-minute cadence.

A cycle:
1. load immutable P07 outcome links;
2. create any missing learning cases;
3. aggregate recurrence patterns;
4. create newly eligible research hypotheses;
5. update research queue;
6. render a learning report;
7. seal a cycle receipt.

No upstream science is changed.

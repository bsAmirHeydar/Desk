# Runtime Output

The P04 state contains separate namespaces:

- `upstream_pressure_reference`;
- `upstream_transmission_reference`;
- `evidence_summary`;
- `unreleased_pressure`;
- `opposing_move_maturity`;
- `transmission_inflection`;
- `latent_causal_reserve`;
- `release_readiness`;
- `release_lifecycle`;
- `liquidity_hypotheses`;
- `research_blockers`;
- `confidence`;
- `integrity`.

No field grants a trade. No field mutates P02 or P03.

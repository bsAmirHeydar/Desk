# AD-V2-P04 Release Notes

P04 adds the generic latent-pressure and release science required to distinguish **causal force accumulation** from price momentum.

Key laws:

- price distance never matures an opposing move;
- time elapsed never matures an opposing move;
- unreleased pressure is not pressure minus price;
- a price reversal is not a release;
- Release requires independent non-price evidence;
- newly discovered causal opposition forces a P02 recomputation;
- event-reset risk can cap readiness;
- liquidity/absorption labels remain hypotheses, never price-derived facts;
- P04 remains shadow-only and grants no trade permission.

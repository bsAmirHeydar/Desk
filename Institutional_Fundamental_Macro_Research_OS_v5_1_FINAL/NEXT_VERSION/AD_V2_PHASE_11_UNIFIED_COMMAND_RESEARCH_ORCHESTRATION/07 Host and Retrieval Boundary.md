# Host boundary

P11 reuses the already-certified R3 `PRODUCTION_COMMAND` host binding. It does not introduce a second secret/configuration path. The host must support MODEL_PROCESS; EVIDENCE_RETRIEVAL is required for fully automatic one-command live response sampling.

If live retrieval is unavailable, P11 fails closed or accepts an explicit prebuilt P10 input pack. It does not invent current market observations.

# Post-P10 operating model

After P10, routine work is evidence collection rather than phase proliferation:

1. run Gold research;
2. create P06 V2 shadow state;
3. let P08 freeze eligible future commitments;
4. ingest future observations;
5. mature outcomes/calibrate through P07/P08;
6. let P09 learn from recurring failures;
7. build a challenger phase only when evidence justifies a specific scientific change.

P10 is therefore the integrated V2 shadow release candidate, not the end of empirical validation.

# AD-V2-P08 — Continuous True-Forward Shadow Operations

P08 operationalizes the empirical program created by P07. It does **not** create a new market science and does not promote V2 into V1 authority.

## Mission
1. discover completed P06 Gold capsule extensions;
2. freeze eligible P07 TRUE_FORWARD commitments promptly and automatically;
3. enforce strict point-in-time latency so late-discovered runs are never mislabeled true forward;
4. ingest future Gold observations through an explicit append-only observation contract;
5. mature outcomes only under an evaluation profile sealed before the commitment;
6. continuously refresh calibration and promotion-eligibility receipts without auto-promotion;
7. provide scheduler, cycle receipts, operational status, failure recovery and audit trails;
8. keep V1 permission authoritative and broker authority NONE.

P08 is an operations layer. P02 owns Pressure, P03 Transmission, P04 latent/release, P05 Gold specialization, P06 run composition/persistence, and P07 forward validation/promotion governance.

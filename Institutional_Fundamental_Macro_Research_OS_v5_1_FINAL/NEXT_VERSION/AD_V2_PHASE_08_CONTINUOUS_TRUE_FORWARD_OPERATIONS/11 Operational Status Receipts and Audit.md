# Operational status and receipts

Each cycle creates an immutable receipt with:
- discovered P06 runs;
- new commitments;
- late rejections;
- duplicate/idempotent skips;
- imported observations;
- mature outcomes linked;
- pending/profile-required counts;
- latest P07 calibration and promotion-observation state;
- explicit authority declaration.

Status is derived from append-only stores and never from console success text alone.

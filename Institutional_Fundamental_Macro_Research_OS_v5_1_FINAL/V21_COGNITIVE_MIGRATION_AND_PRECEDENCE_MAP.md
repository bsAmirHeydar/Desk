# V21 Cognitive Migration and Precedence Map

V21 is an overlay/hardening release on top of V20. D1–D4 are preserved.

## Precedence
`D1 truth → Module 89 Fundamental horizon states → Module 90 Narrative → Module 93 Timing → D2 states → Module 103 cognitive synthesis → Module 101 D3 causal modulation → Module 102 D4 promoted authority → Module 94 operational gate`.

Module 103 may fail-close an unresolved cognitive state before D3, but it cannot create permission or Direction. Module 101 remains the D2-to-edge authority. Module 102 remains the only route for empirically promoted policy changes. Module 94 remains the operational safety authority.

## Legacy prompts
V19 and V20 production prompts remain allowlisted only as delegated subengines/regression entrypoints. New live analysis must start at the V21 Module 103 production prompt.

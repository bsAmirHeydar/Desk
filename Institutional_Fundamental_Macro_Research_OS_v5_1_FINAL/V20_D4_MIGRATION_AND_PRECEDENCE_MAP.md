# V20 D4 Migration and Precedence Map

## V19 → V20
V19 D3 remains the baseline causal-adjudication policy. V20 adds Module 102 after D3 to govern immutable forward validation, paired counterfactuals, calibration, promotion, drift and retirement.

## Precedence
1. Module 95 Fact Constitution.
2. Module 89 Fundamental Direction/Force.
3. Module 90 Narrative Transmission.
4. Module 93 Temporal Clearance.
5. Modules 96–100 D2 scientific states.
6. Module 101 D3 causal integration.
7. **Module 102 D4 promotion-registry governance.**
8. Module 94 operational/portfolio safety remains applicable as lower-level production control.

## Initial V20 behavior
The promotion registry is empty, so V20 produces the same permission as the V19 D3 baseline while emitting the new D4 Authority Receipt and forward-research record.

## Future promotion
A future reviewed registry change may grant narrow modifier authority. No promotion can create a direction absent a valid Fundamental directional thesis.

# TRACE Credit Transaction Intelligence

## Mission
Use disseminated fixed-income transactions as a direct transaction layer for credit/liquidity diagnostics without turning bond prints into a generic risk-on/off score.

## Separation
`TRACE TRANSACTION != IDENTIFIED INVESTOR FLOW != CREDIT SPREAD STATE != EQUITY DIRECTION`

A trade is direct. Its economic interpretation requires security, side/classification method, size/cap, liquidity regime, sector, rating/duration and reference price/yield context.

## High-value uses
- detect deterioration/improvement in transaction liquidity;
- test whether an equity growth-scare narrative is confirmed by credit;
- identify concentrated stress by sector/issuer cohort;
- distinguish mark-to-market spread changes from active transaction conditions.

## Limits
Dissemination rules, caps and access tiers are product-specific. Historical/public views and subscription real-time data must not be conflated. Equity permission remains Fundamental-only; credit transaction evidence is a causal/transmission diagnostic.

# Retrieval, Source Canon, Integration and Final Adversarial Audit — Scenario, Tail and Update System

## Scenario design

Scenarios are mechanism-specific joint states, not lists of optimistic and pessimistic numbers. Each scenario must specify driver changes, policy response, financing and balance-sheet effects, cross-domain transmission, signposts, timing, reversibility and residual unknowns.

## Scenario grid

| Scenario | Driver configuration | Policy response | Cross-domain effect | Signposts | Expiry |
|---|---|---|---|---|---|
| Base | current modal state | expected response | gradual priced adjustment | state persists | next material release |
| Alternative | one key axis shifts | partial offset | relative repricing | leading confirmation | invalidation |
| Adverse tail | multiple constraints bind | delayed or ineffective | nonlinear contagion | funding or physical break | stabilization |
| Benign tail | capacity or credibility improves | less restrictive | risk-premium compression | broad independent evidence | repriced baseline |

## Driver axes

- query classification
- domain retrieval
- claim evidence lineage
- contradiction and unknowns
- analysis output consistency
- current versus historical separation
- coverage and anti-boilerplate
- adversarial validation

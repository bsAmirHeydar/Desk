# Current and Historical Unified Query Router

## Current mode

Require a precise as-of timestamp, live source verification, current pricing baseline, latest available data vintage, current policy and institutional state, and explicit freshness limits.

## Historical mode

Require a historical cutoff, contemporaneous data vintage, historical constituent and contract definitions, contemporaneous expectations, archive gaps and a separately labeled ex-post audit.

## Routing sequence

1. Classify analysis object and mandate.
2. Assign direct release and dependencies.
3. Build horizon stack.
4. Retrieve state, expectations, valuation, constraints and rival models.
5. Build cross-domain confirmation map.
6. Generate scenarios and unknowns.
7. Populate institutional output contract.
8. Run Release 14 adversarial checks.

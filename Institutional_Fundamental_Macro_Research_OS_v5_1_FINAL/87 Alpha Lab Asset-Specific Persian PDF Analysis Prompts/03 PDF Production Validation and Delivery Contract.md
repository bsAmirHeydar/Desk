# PDF Production Validation and Delivery Contract

## Mandatory artifact

The execution is incomplete until an actual Persian PDF file is created and delivered. Do not stop at an outline, Markdown report, HTML preview or explanation of what the PDF would contain.

## Production procedure

1. Complete the research and evidence ledger.
2. Write the Persian report using [[87 Alpha Lab Asset-Specific Persian PDF Analysis Prompts/01 Alpha Lab Persian PDF Design System]].
3. Use the available PDF-generation toolchain in the execution environment.
4. Preserve right-to-left direction at document, paragraph, table and callout levels.
5. Embed or use an available Persian-capable font consistently.
6. Generate the PDF artifact.
7. Render or inspect every PDF page before delivery.
8. Correct and regenerate if any page has clipping, overlap, broken glyphs, incorrect direction, table overflow, orphaned headings, blank pages or unreadable charts.
9. Confirm the final filename, page count and data cutoff.

## Required report behavior

- The executive conclusion must be simple and plain Persian.
- Institutional detail must remain available in later sections and appendices.
- The report must distinguish facts from inference and unknowns.
- It must show conclusions separately for structural, cyclical, tactical, multi-day and intraday/event horizons when relevant.
- It must state what evidence would invalidate or materially change the view.
- It must not issue a personalized order or guarantee performance.

## Delivery response

After successful creation, respond briefly in Persian with:

- one-sentence completion status;
- the PDF download link;
- the exact as-of timestamp;
- the internal QA state.

Do not paste the full report into the chat unless explicitly requested.


## Daily report production

For daily profiles, apply [[87 Alpha Lab Asset-Specific Persian PDF Analysis Prompts/12 Daily Persian PDF Report Contract]]. Confirm that the report includes the previous-close change ledger, today's catalyst timeline, daily state, persistence class, invalidation evidence and next update time. Reject a daily PDF that is dominated by structural macro background or fails to explain what changed today.

# Point-in-Time Case-Based Analog Memory

Historical analogues can complement causal reasoning when selected correctly. V21 selects analogues using only state features observable at the historical cutoff. It is forbidden to choose past episodes because their future price path looks like the current one.

The analogue output identifies the matching features, missing features, regime coverage, sample size, independent-root count and descriptive outcome distribution. Analogues remain shadow/descriptive until D4 validates an incremental policy effect.

If the current regime contains an important feature absent from the historical sample, the system must say so rather than forcing similarity.

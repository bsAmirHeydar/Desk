# Event Fast-Path Multi-Stage Cognitive State Machine

Major events require repeated state construction because the dominant interpretation often changes after the headline.

Use `PRE_EVENT → RELEASE → FACT_VERIFICATION → INITIAL_SHOCK → T+5M REASSESS → T+15M REASSESS → T+30M OR STABILIZATION`. At each stage update the surprise object, reaction function, causal leaders, hypotheses, scenario tree, flow/funding/mechanics and driver transition state.

A first-minute price move is diagnostic, not proof. If the expected leader later reverses or a composition detail changes the reaction function, the scenario tree transitions rather than rewriting history. Each stage keeps its own cutoff and evidence pack.

# Source Reliability and Incremental Information Value Learning

Source tier is not the same as empirical decision value. Official sources can be slow; proxies can be noisy; expensive feeds can add little incremental information after other states are known.

V21 therefore hands D4 source-level and feature-level attribution metadata. Forward research can measure whether a source reduces false permissions, improves timing, narrows uncertainty or adds no measurable value.

The production brain does not automatically downweight a source from a short sample. It records hypotheses for later validation. D1 truth hierarchy remains the admission authority.

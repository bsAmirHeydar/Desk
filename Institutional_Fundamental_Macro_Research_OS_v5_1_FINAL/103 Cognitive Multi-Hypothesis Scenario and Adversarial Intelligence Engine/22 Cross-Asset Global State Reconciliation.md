# Cross-Asset Global State Reconciliation

Each market can have a legitimate local driver. V21 therefore does not force one global story. It does, however, test whether the six market-level conclusions imply mutually incompatible statements about the same root.

For example, Nasdaq and Gold can both be bullish for different reasons. That is not inconsistency. But if one market analysis claims “US real yields are falling strongly” while another same-cutoff analysis relies on “US real yields are rising strongly” with no horizon distinction, the global reconciler flags the conflict.

The reconciler is an audit layer, not a voting system. It cannot change Direction. It can demand re-examination of same-root claims and expose hidden portfolio concentration around one macro factor.

# Cognitive Loop and Independent State Construction

The production brain must not begin by asking “is this BUY or SELL?” It first constructs the independent scientific states as cleanly as possible: Fundamental, Narrative, Timing, Positioning, Flow, Funding, Mechanics and Capacity. Each state keeps its own evidence class and unknowns.

Only after those states exist does Module 103 synthesize them. This reduces anchoring: a bullish Fundamental thesis must not cause the Flow analyst to label ambiguous activity “buying,” and a strong price move must not cause Narrative to retrofit a story.

The cognitive loop may revisit a state when a genuine causal contradiction is found, but every revision must be reason-coded: new fact, source correction, horizon mismatch, regime remap, root-dependency discovery, driver transition or model-disagreement escalation. Revision because “the price moved against us” is not enough.

The loop terminates when either a minimum sufficient causal explanation survives the adversarial review or the system reaches a legitimate `CONTESTED / INSUFFICIENT_EVIDENCE` state.

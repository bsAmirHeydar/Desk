# Scenario Tree and Conditional Path Intelligence

The V21 brain is explicitly multi-scenario. A production tree normally holds two to six paths. The tree may include a base case, extension, adverse path, tail risk, alternative regime and mechanical path when relevant; it must not mechanically create all six every time.

Every scenario has source hypotheses, horizon, qualitative plausibility band, required conditions, early indicators, confirmation triggers, invalidation triggers, expected leaders, expected market signatures and explicit transition paths to other scenarios.

Scenarios are conditional plans, not predictions with fabricated probabilities. Use `PRIMARY / COMPETITIVE / SECONDARY / TAIL / UNRESOLVED` unless D4 has empirically authorized a numerical probability estimand.

The final report must show the strongest adverse scenario even when the base case is clear. For day trading, scenario triggers should be observable quickly enough to matter to the permission validity window.

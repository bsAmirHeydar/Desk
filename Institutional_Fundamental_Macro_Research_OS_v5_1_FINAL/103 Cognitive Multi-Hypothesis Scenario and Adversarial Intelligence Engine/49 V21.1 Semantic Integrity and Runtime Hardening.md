# V21.1 Semantic Integrity and Runtime Hardening

V21.1 is a precision release, not a feature-expansion release. It enforces meaning across the existing V21 cognitive objects.

## Core laws
1. **Present or explicit applicability.** No first-class cognitive state disappears silently.
2. **Traceable load-bearing evidence.** Material hypothesis evidence references D1 facts/lineage or is explicitly partial/unavailable.
3. **Observable triggers.** Material confirmations, invalidations, transitions and pre-mortem warnings are monitorable predicates/events/manual observations.
4. **Cross-field semantic identity.** Instrument, cutoff, active horizon, IDs and Direction must reconcile across the pack.
5. **Scenario parsimony.** Use 1–6 materially distinct paths; merge duplicates; numeric probabilities require D4 calibration.
6. **Module 89 owns every Fundamental horizon, including `SWING_2_8W`.**
7. **Full cognitive telemetry.** D4 receives the states needed to learn whether hypotheses, scenarios, uncertainty and abstention were useful.
8. **Adaptive detail.** Complete machine state; proportional human explanation.

This release does not promote portfolio authority, create new trading strategies, or add unvalidated predictive features.

# Learning Promotion Governance

Promotion path:

`OBSERVATION → CANDIDATE → VALIDATED → CANONICAL`

A single anecdote must not become a permanent rule. Promotion requires repeated point-in-time evidence, rival-model checks, documented failure cases and cross-regime/cross-market generalization where the proposed rule claims generality.

- `OBSERVATION`: one or more facts worth tracking.
- `CANDIDATE`: a falsifiable analytical adjustment with validation plan.
- `VALIDATED`: sufficient forward evidence supports the adjustment within a defined scope.
- `CANONICAL`: incorporated into core methodology with exact rationale, affected modules and rollback condition.

Contradictory evidence remains in the ledger; it is not deleted to improve apparent performance.

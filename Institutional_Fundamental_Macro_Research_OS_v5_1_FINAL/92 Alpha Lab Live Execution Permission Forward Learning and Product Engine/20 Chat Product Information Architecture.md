# Chat Product Information Architecture

The task response should remain compact and decision-oriented while linking the complete HTML.

Recommended visible chat summary:
- timestamp;
- six-row `Symbol | Edge Level | Permission` matrix;
- one cross-market sentence if materially useful;
- direct link to complete HTML;
- optional direct link to minimal execution JSON.

Do not paste the entire Full-Vault report into chat when the HTML already contains it. The HTML is the primary deep human artifact.

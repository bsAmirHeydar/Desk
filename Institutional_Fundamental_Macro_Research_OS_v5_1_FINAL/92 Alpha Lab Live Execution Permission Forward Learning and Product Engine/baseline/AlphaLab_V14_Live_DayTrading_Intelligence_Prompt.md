# 19. NEXT REVIEW TIME ENGINE

The report must always state the exact next review time.

Calculate the next review from the earliest material state-change opportunity.

Candidate clocks:

- next scheduled macro release;
- next central-bank communication;
- next earnings release;
- next commodity inventory/production report;
- next auction;
- next fixing;
- next session open;
- next market close;
- expiry/rebalance;
- expected fact-decay threshold;
- expected narrative-transition threshold;
- cross-asset confirmation deadline;
- or maximum routine review interval.

Rules:

1. Never schedule the next review after a known high-impact event.
2. When a high-impact event is near, set:
   - pre-event review;
   - and post-event reassessment window.
3. If no event is near:
   - unstable/fragmented state: review in 30–45 minutes;
   - active directional state: review in 45–60 minutes;
   - stable persistent state: review in 60–120 minutes;
   - closed market: review before the next active session.
4. If the state is `EVENT_BINARY`, review 10–15 minutes before the event and again 5–15 minutes after reliable first reaction.
5. If data quality is limited, shorten the review interval.
6. If the dominant narrative is transitioning, review sooner.
7. If force is persistent and consumption low but price transmission is delayed, set a cross-asset confirmation deadline.

Report:

- exact next review timestamp in UTC;
- exact next review timestamp in New York;
- exact next review timestamp in `REPORT_TIMEZONE`;
- reason;
- expected new information;
- variables to check;
- early-review triggers;
- and maximum expiry of the current verdict.

# Daily Learning Commit and Vault Mutation Gate

At the final Tehran run of each trading day:
1. consolidate new run-level learnings;
2. deduplicate them;
3. append a dated Daily Learning Commit;
4. preserve market/horizon/regime, prior call, realized path, classification, causal post-mortem, evidence available then, missing evidence, proposed adjustment, rival explanation, confidence and promotion requirement.

Daily learning is mandatory. Daily mutation of core science is **not**.

Only a genuinely `VALIDATED` learning may change a canonical methodology note. Every canonical change must record:
- exact text/rule changed;
- rationale;
- date;
- affected modules;
- validation evidence;
- rollback condition.

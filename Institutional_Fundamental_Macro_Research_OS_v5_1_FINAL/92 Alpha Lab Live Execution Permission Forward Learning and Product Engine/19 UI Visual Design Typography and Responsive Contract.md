# UI Visual Design, Typography and Responsive Contract

## Visual system
- premium institutional editorial feel;
- matte black/obsidian navigation surfaces;
- warm ivory/cream reading surfaces;
- restrained muted gold accents;
- subtle semantic colors for up/down/neutral/warning;
- avoid gradient-heavy dashboards, glass overuse, decorative clutter and card soup;
- generous but controlled spacing and readable long-form Persian hierarchy.

## Typography
- Persian: `B Lotus` via `local()` only; do not bundle or redistribute font files;
- fallback: professional Arabic/Persian system stack;
- English/Latin: Spectral, with serif fallback;
- explicit bidi handling for tickers, timestamps and English source titles.

## Mobile
- purpose-built mobile navigation, not scaled desktop;
- compact readable typography; avoid oversized headings/cards;
- market matrices become stacked horizon cards;
- Compare stacks cleanly;
- full-analysis subnavigation remains reachable;
- touch targets remain usable without making the interface visually bloated.

## Navigation
Real browser Back/Forward behavior, breadcrumbs, persistent desktop market nav, mobile drawer/bottom navigation and global search across narratives, drivers, scenarios and sources.

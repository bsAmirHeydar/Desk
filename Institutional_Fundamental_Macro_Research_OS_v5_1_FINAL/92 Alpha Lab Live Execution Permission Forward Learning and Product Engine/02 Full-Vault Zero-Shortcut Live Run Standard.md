# Full-Vault Zero-Shortcut Live Run Standard

`FULL-VAULT` means **all relevant canonical science and specialist adapters are actively considered for every symbol**. It does not mean blindly loading every note regardless of relevance; V13 dynamic retrieval remains valid.

Every run must:
- freeze point-in-time timestamps and source cutoff;
- freshly re-research all six production symbols rather than copy prior states;
- analyze MICRO 0–15m, SHORT 15–60m, SESSION 1–6h, DAILY, NEXT_24H and 2–5D separately;
- construct the complete relevant fact universe;
- adjudicate force and opposing force;
- distinguish available driver from ACTIVE driver;
- test driver activation, conditional sensitivity and transmission integrity;
- classify confirmations as causal, independent, mechanical/correlated, lagging, contradictory or unavailable;
- identify attention, ignored facts, dominant/challenger narratives, validity, dominance, price control, persistence, saturation, fragility and transition triggers;
- estimate consumption and remaining pressure independently;
- evaluate reversal hazard, horizon conflict, flow/positioning/liquidity/volatility evidence, event risk, scenarios and invalidations;
- state exact next-review and early-review triggers;
- cap confidence for unavailable evidence.

A quick headline refresh, one-driver commentary, partial-symbol refresh or copied prior state must never be labelled `FULL-VAULT`.

# V10.2 Daily Fundamental Context Release Notes

V10.2 adds a complete day-horizon fundamental analysis layer to the four Alpha Lab PDF prompts for Nasdaq 100, S&P 500, Gold and EURUSD.

## Added

- Daily pre-market analysis profile.
- Live-session update profile.
- Post-event surprise and repricing profile.
- End-of-day attribution profile.
- Previous-close change ledger.
- Overnight and session-handoff map.
- Daily catalyst calendar with exact timezones.
- Causal-leader scoreboard.
- Day-type and persistence classifications.
- No-event and flow-led day framework.
- Daily fundamental state codes.
- Daily Persian PDF contract and launchers.

## Design principle

Daily reports prioritize current-day information and session causality. Structural and cyclical material remains available as inherited context but may not dominate the report unless a genuine regime change is occurring.

# Missing Data and Licensed Coverage

A D2 run must distinguish:
- source exists but not connected;
- source connected but stale;
- source does not cover participant/venue;
- public proxy exists but is indirect;
- no defensible evidence exists.

Never convert `LICENSED_REQUIRED` to a public proxy while preserving the same confidence. A proxy may be used only as its own fact class with explicit limitations.

Because V18 D2 is shadow-only, missing D2 data does not by itself kill an otherwise valid V17 permission. It is disclosed and logged for D3/D4 research. Existing D1 decision-critical evidence rules still apply to the existing production sciences.

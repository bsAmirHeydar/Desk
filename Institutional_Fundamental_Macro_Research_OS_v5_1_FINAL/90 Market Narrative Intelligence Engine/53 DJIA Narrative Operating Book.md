# DJIA Narrative Transmission Operating Book

Narrative does not create DJIA direction. It tests whether the current Fundamental causal root is being selected and transmitted.

Tournament when material: broad US equity/rates, cyclical-industrial growth, financial/rates, health/regulatory, industrial/trade policy, and one/few price-weighted constituent shocks.

A broad Nasdaq/S&P story is `ALIGNED` only when current DJIA constituent causality shares the same root. Use price-blind fact validity first, then price/breadth/flow evidence only for transmission/dominance. Return the V16.1 narrative-clearance state, not an independent BUY/SELL.

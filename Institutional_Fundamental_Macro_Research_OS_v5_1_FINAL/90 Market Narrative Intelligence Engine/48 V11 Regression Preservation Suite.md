# V11 Regression Preservation Suite

V12 fails if Module 89 or the V10.4/V11 hybrid state is weakened.

The regression suite verifies:

- Module 89 canonical files and schema remain present;
- V11 force, consumption, remaining pressure, persistence, reversal risk and asymmetry semantics remain authoritative;
- 25 V10.4 record types remain readable;
- event micro-windows, no-change and decay records remain supported;
- daily and asset-specific prompt routes remain present;
- ordinal scores remain distinct from probabilities;
- unavailable proprietary data remain explicit;
- no V12 field silently overwrites V11 history.

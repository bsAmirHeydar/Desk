# Cross-Science Root-Cause Fusion

Module 101 constructs one deduplicated root map across Positioning, Flow, Funding, Mechanics and Capacity.

A single causal event may generate descendants in several sciences. D3 tracks:
- `root_id`;
- parent/child lineage;
- observation type;
- materiality;
- whether the root is independent of the Fundamental driver.

No modifier becomes stronger merely because the same root appears in multiple datasets.

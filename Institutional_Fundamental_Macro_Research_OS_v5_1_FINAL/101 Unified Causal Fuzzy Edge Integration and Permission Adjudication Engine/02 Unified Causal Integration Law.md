# Unified Causal Integration Law — V21 Hardened

Every D2 science enters Module 101 through an Integration Vector containing:

`science → causal_channel → alignment_to_fundamental → obstruction_class → materiality → evidence_grade → root_id → persistence`.

V21 adds an optional evidence-confidence **band** and cognitive context; a numeric field is legacy ordinal metadata, not a calibrated predictive probability.

The engine never sums science scores.

## Causal roles
- `SUPPORT`: strengthens transmission evidence but cannot create direction.
- `FRICTION`: reduces asymmetry/validity without invalidating direction.
- `DELAY`: thesis may remain valid but the current execution window is temporarily unusable.
- `TRANSMISSION_BREAK`: directional thesis exists but current market transmission is materially broken.
- `EXECUTION_BLOCK`: research edge may exist, but intended execution is infeasible.
- `NONE`: no material D3 effect.

## V21 multi-channel root law
One independent root may contain several material channels. Deduplicate the root for independence, but preserve every channel. A root containing both clean support and material opposition is `CONTESTED` and does not count as clean supportive confirmation.

## Precedence
1. Fact/evidence block.
2. Fundamental Direction/Force at the active strategy horizon.
3. Module 103 cognitive fail-closed constraints.
4. Narrative and Timing clearance.
5. D3 decision-critical unknowns.
6. Capacity execution block.
7. Mechanical delay/fragmentation.
8. Funding/flow transmission break.
9. Fragility/asymmetry/validity constraints.
10. Support/confirmation labels.

Positive evidence never cancels a higher-precedence obstruction merely by count.

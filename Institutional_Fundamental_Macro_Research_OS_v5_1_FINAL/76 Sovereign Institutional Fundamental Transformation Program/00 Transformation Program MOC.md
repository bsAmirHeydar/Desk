# Sovereign Institutional Fundamental Transformation Program

This program converts the Vault from a large reference architecture into a fundamental-only, source-controlled, point-in-time, model-implemented, portfolio-aware and independently governed institutional research platform.

## Program principles

- A document is not a production capability.
- A model name is not an implemented model.
- A source link is not claim-level evidence.
- A historical narrative is not a point-in-time reconstruction.
- A probability is not calibrated until calibration is measured.
- A decision layer has no proven value until it beats a baseline after costs.
- A 10/10 score requires evidence, code, data, operations and governance.

# V16 Institutional Production Control Engine

V16 does not add another opinion layer. It converts existing V11–V15.1 science into a measurable, auditable and fail-closed production system.

## Mandatory decision chain

`Production Manifest → Evidence Fabric → V11 Fundamental → V12 Narrative → V13 Instrument → CORE_EDGE_CANDIDATE → V15.1 Timing Clearance → Global Evidence Dependency Firewall → Calibration Status → Portfolio Gate → Operational Gate → Final BUY/SELL/NO_TRADE → M1 Donchian-20 → 4ATR + close-trail → Outcome Ledger → Independent Validation/Learning`

## Immediate enforcement vs shadow-only

**Enforced now:** one production manifest, authority resolution, source/run provenance, evidence-root deduplication, stale/unknown fail-closed behavior, operational kill switch, immutable run/outcome records and deterministic portfolio hard-blocks when an explicit policy limit is breached.

**Shadow until empirically mature:** numeric edge calibration, capital scaling from calibration, statistical state-family ranking and any new learned filter. No new unvalidated rule may reduce or increase live risk merely because it sounds plausible.

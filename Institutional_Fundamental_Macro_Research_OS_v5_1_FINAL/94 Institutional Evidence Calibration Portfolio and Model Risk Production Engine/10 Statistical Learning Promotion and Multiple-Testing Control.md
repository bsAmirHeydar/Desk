# Statistical Learning Promotion and Multiple-Testing Control

`OBSERVATION → CANDIDATE → VALIDATED → CANONICAL` remains, but V16 adds machine-checkable evidence requirements.

A promotion record must include sample size, independent-root-event count, market/regime coverage, holdout results, effect direction stability, failure cases, multiple-testing family, retirement condition and validator sign-off.

Discovery rules are never promoted on in-sample performance alone. If many hypotheses are screened, the research record must state the correction/control method or mark the finding exploratory. The included tool supports Benjamini-Hochberg bookkeeping for batches of supplied p-values; it does not manufacture p-values.

No automatic Vault mutation from a single run is permitted.

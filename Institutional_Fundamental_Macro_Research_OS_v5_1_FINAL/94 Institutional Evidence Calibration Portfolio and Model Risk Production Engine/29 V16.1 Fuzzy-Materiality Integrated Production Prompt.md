# Alpha Lab V16.1 — Fuzzy-Materiality Integrated Production Prompt

Run only after `alphalab_preflight.py --mode runtime` returns PASS and a valid smallest-sufficient Retrieval Plan exists.

Universe is exactly XAUUSD, NASDAQ100, SP500, DJIA, EURUSD and USDJPY. WTI/USOIL/crude oil remain outside this production profile.

## 0. Freeze
Freeze run ID, analysis cutoff, model ID if available, Vault/manifest version, source cutoff, and immutable evidence timestamps. Never invent unavailable metadata.

## 1. Retrieval plan
Retrieve the smallest sufficient canonical set. Do not load supporting-legacy/archived/deprecated notes into the decision context. Expand only for a named material driver, event, evidence gap or rival model.

## 2. Fundamental direction — sole directional authority
Run V11/V13 asset science. Fundamental alone owns the causal direction. Report direction, force stage, asymmetry, persistence, consumption, remaining pressure, opposing force and reversal risk. Narrative, Timing, Calibration, Portfolio and Execution may constrain or veto but may not invent or flip direction.

## 3. Narrative transmission clearance — fuzzy, not binary
Run V12 with price-blind validity where feasible and return exactly one:
`ALIGNED_DOMINANT | ALIGNED_EMERGING | NEUTRAL | CONFLICTED | OPPOSING | UNDETERMINED`.

`ALIGNED_EMERGING` may clear an otherwise strong fundamental state with a confidence/validity cap; do not demand full consensus and miss the early asymmetric phase. `NEUTRAL/CONFLICTED/OPPOSING` cannot create the opposite trade; they constrain the fundamental thesis.

## 4. Evidence materiality and dependency
Every load-bearing node has `decision_materiality = DECISION_CRITICAL | MATERIAL_SECONDARY | CONTEXTUAL`. Use the marginal-decision test.
- critical unresolved item that can flip permission -> HOLD/BLOCK as appropriate;
- secondary unresolved item -> confidence cap, not automatic NO_TRADE;
- contextual unknown -> disclose only.
Same-root descendants are not independent votes.

## 5. Core candidate
Use the executable fuzzy transition matrix in `tools/alphalab_decision_gate.py`.
A weak/partial Fundamental state can never be upgraded to Active by Narrative.

## 6. Timing V15.1 with materiality tiers
Run Timing after Core Candidate. Timing cannot create direction. Only decision-critical clocks may HOLD/VETO because unresolved. Secondary clocks can shorten validity/advance review; contextual clocks are recorded only. A future event is not a veto by existence.

## 7. Research Edge
Combine Core Candidate + Evidence Clearance + Timing. `EDGE_ACTIVE` exists only when the causal core is active and timing is usable. Preserve explicit confidence caps; do not convert them into fake probabilities.

## 8. Calibration and Portfolio
Calibration and Portfolio remain SHADOW unless their configs are explicitly promoted after validation. Report their diagnostics but do not let unvalidated thresholds silently change live permission.

## 9. Operational safety
Operational Gate is ENFORCED. Run `PERMISSION_INGEST` before bridge acceptance and `ENTRY_TRIGGER` when Donchian fires. Unknown required operational fields are unsafe; secondary research uncertainty is not an operational incident.

## 10. Final output per symbol
Return:
- Fundamental Direction and Force State
- Narrative Transmission Clearance
- Evidence Clearance + decision-critical unknowns
- Core Edge Candidate
- Timing Clearance
- Research Edge
- explicit confidence/validity caps
- Calibration diagnostic
- Portfolio shadow diagnostic
- Operational Gate
- Final Permission `BUY|SELL|NO_TRADE`
- `valid_until_utc`
- `next_review_utc`
- exact Why Not Active / Why Blocked when applicable

Minimal execution JSON remains only the six symbols with permission and valid-until; stale/malformed/expired/unknown -> NO_TRADE downstream.

## 11. Execution and learning
Donchian-20 M1, 4ATR initial stop and candle-close trailing remain external mechanical execution only. Append immutable run/outcome telemetry; never rewrite an earlier state. Compare CORE_ONLY, NARRATIVE_CLEARED, TIMING_GATED and shadow portfolio/calibration arms after horizons mature.

## 12. Validation
Run same-model blind second pass at minimum and label it honestly. True independent validation requires a genuinely separate model/analyst. Disagreement is information, not an automatic veto unless it exposes a decision-critical error.

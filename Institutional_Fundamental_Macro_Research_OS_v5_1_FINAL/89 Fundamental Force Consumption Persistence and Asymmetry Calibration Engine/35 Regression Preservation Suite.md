# V11 Regression Preservation Suite

## Decision purpose

Prove that V11 adds measurement and calibration discipline without weakening the V10.4 hybrid state engine, record density, event micro-windows, asset prompts or fundamental-only boundary.

## Governing distinctions

- New fields do not invalidate old fields.
- Semantic preservation differs from link preservation.
- A patch can pass structure and still fail methodology.
- Regression failures block full certification.
- Deprecated authority remains discoverable through migration maps.

## Operating method

1. Capture baseline file and authority manifests.
2. Verify all 25 V10.4 record types remain represented.
3. Verify daily/session/event/no-change and T-60 through T+60 support.
4. Verify old schema names and prompt entry points remain readable.
5. Run link, frontmatter, fence, authority and false-certification checks.
6. Compare canonical benchmark outputs for required distinctions.
7. Publish machine-readable and human-readable regression reports.

## Required outputs

- `record_type_preservation`
- `micro_window_preservation`
- `prompt_preservation`
- `schema_compatibility`
- `link_delta`
- `authority_delta`
- `semantic_gates`
- `certification_status`

## Failure modes and controls

- **Failure:** Passing because files exist  
  **Control:** Inspect required concepts and fixtures.
- **Failure:** Renaming without redirect  
  **Control:** Require migration map.
- **Failure:** Hiding known failures  
  **Control:** Certification verdict must expose failures.

## Hard regression assertions

- Direction remains separate from edge.
- Intensity remains separate from confidence.
- Consumption remains multidimensional.
- Remaining pressure is not an arithmetic complement.
- Historical states remain immutable.
- First release and revision remain distinct.
- Missing proprietary data remain explicit.
- Persian PDF contracts and four asset prompts remain linked.
- The upgrade does not introduce chart-pattern entry logic.

# Prompt and Analysis Version Ledger

Every analysis records Vault version, prompt version, retrieval-registry version, source-verification timestamp and QA-rubric version. A material prompt change increments the major or minor version and records the changed gates. Historical analyses preserve the exact prompt and Vault version used.

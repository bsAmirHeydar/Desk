# Claim-Level Evidence Backfill Standard

Every load-bearing claim receives a stable claim ID and these fields: claim text; type; canonical note; source organization; exact document/series/form; exact page/table/section/item; publication timestamp; reference period; vintage; transformation; units; scope; limitations; opposing evidence; reviewer; and last verification date.

Source routes embedded in the canonical monographs are the minimum ledger, not permission to cite a homepage. Live analysis verifies the current official document. Historical analysis preserves the admissible source version.

# Retrieval Regression and Duplicate-Title Audit

The release validator rejects broken links, ambiguous bare links, duplicate generic MOC filenames, multiple canonical notes for the same analysis object, links to deprecated Mega Canon content and prompt routes that bypass the canonical registry.

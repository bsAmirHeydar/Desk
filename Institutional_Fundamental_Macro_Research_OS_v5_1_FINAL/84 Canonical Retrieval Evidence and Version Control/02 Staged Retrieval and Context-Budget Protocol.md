# Staged Retrieval and Context-Budget Protocol

## Stage A — object resolution

Read the query, exact instrument/entity, cutoff and horizon. Retrieve the Home page, this protocol and one direct canonical monograph.

## Stage B — dependency expansion

Retrieve at most six canonical dependency monographs selected by causal necessity: macro state, financing/policy, country, cross-asset, valuation/physical and method. Do not retrieve entire folders.

## Stage C — evidence

Retrieve exact source contracts and current/historical documents. The evidence set, not the size of the Vault, determines report quality.

## Stage D — exception retrieval

Use supporting legacy notes only for a named specialist sub-question absent from the canonical monographs. Record the reason.

## Hard limits

A Reading Ledger containing many irrelevant notes is a failure. Repeated prose does not count as coverage. The router must summarize why each note is necessary and identify which causal node it informs.

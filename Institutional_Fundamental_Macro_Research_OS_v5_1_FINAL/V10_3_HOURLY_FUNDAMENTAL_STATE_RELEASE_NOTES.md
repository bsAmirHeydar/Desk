# V10.3 Hourly Fundamental State Engine Release Notes

V10.3 adds a practical hour-by-hour fundamental monitoring layer to Nasdaq 100, S&P 500, Gold and EURUSD prompts.

## New outputs

- direction code and -100/+100 ordinal score;
- intensity;
- confidence;
- information absorption;
- repricing completion;
- flow exhaustion;
- narrative saturation;
- catalyst freshness;
- remaining fundamental pressure;
- state phase;
- move-quality classification;
- causal driver stack;
- cross-asset confirmation;
- persistence and half-life;
- reversal risk;
- path asymmetry;
- fundamental edge availability;
- change from prior snapshot;
- no-material-update state;
- event micro-window snapshots;
- historical hourly replay without future leakage.

The hourly engine does not manufacture a new conclusion every hour and does not introduce technical-analysis rules.

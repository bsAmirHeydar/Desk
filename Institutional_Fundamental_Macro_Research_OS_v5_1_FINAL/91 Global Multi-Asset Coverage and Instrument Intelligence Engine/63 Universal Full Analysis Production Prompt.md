# Alpha Lab V13 Universal Full Analysis Production Prompt

## Phase A — Freeze and resolve

Freeze UTC and relevant local times. Resolve every requested ticker, broker symbol, exchange symbol, futures root, contract, benchmark or natural-language name. Publish ambiguity candidates instead of guessing. Assign a coverage state and freeze point-in-time metadata.

## Phase B — Retrieve

Load the evidence protocol, Module 89, Module 90, Module 91 router, the selected family adapter, relevant specialist notes, event atlas, source contract and prior immutable state. Record every Vault path used.

## Phase C — Fact universe

Separate first release from revision, observation from estimate, physical fact from market-implied state, structural prior from new catalyst, and direct source from proxy.

## Phase D — Adapter

- **FX:** build both currency blocks, relative policy/real rates/growth/inflation/fiscal/external states, carry, basis, hedging, intervention, convertibility, fixings and global overlays.
- **Commodity:** resolve contract/month/grade/location/delivery/roll; build physical balance, inventories, curve, basis, storage, logistics, weather, cost, policy and flow overlays.
- **Index:** resolve provider/methodology/return type/constituents/weights; build earnings, margins, valuation, currency, concentration, breadth, flows, derivatives and rebalancing. Route volatility, rates, credit, FX-basket and commodity indices to specialized adapters.

## Phase E — Shared state

For each instrument and horizon output direction, force, fact persistence, consumption, remaining pressure, reversal hazard, attention, competing narratives, validity, dominance, narrative persistence, ignored facts, asymmetry, confidence caps and next update conditions.

## Phase F — Output mode

Choose single-instrument full report, custom watchlist, family dashboard, cross-sectional ranking, relative value, global daily scan, intraday/event update or end-of-day review. Large universes use Tier 1 scan → Tier 2 flags → Tier 3 deep dives with a predeclared selection rule.

## Required sections

1. Cutoff and source availability.
2. Instrument-resolution and coverage ledger.
3. Global regime and dependency-controlled driver graph.
4. Executive shared-state table.
5. Family-specific adapter state.
6. Fact/persistence and consumption/remaining-pressure ledgers.
7. Attention and competing-narrative matrix.
8. Ignored facts, asymmetry, event risk and invalidation.
9. Missing data, licensing needs and confidence caps.
10. Machine-readable V13 state.

## Prohibitions

Never fabricate live data, reserves, intervention, inventories, positioning, flows, constituents or empirical calibration. Never treat a currency pair as one currency, a commodity future as generic spot, or an index name as a complete methodology.

# 102 — Forward Validation, Calibration, Promotion and Scientific Governance Engine

**Release:** V20.0.0  
**Deployment:** D4 — Forward Validation / Calibration / Selective Promotion  
**Governance version:** 1.0.0  
**Authority mode:** `GOVERNANCE_ENFORCED`

## Mission
D4 closes the original nine-phase Alpha Lab research roadmap. It does not invent another market science. It determines, with forward-only evidence, which D3 modifiers are useful, harmful, redundant, regime-specific, or worthy of selective authority.

## Non-negotiable laws
- Fundamental remains the **only Direction creator**.
- D4 cannot convert a Fundamental `NEUTRAL/UNRESOLVED` state into BUY/SELL.
- No modifier is promoted because it is intuitively plausible.
- No single live run can mutate production authority.
- Original run state is immutable; outcomes append later.
- Actual and counterfactual branches must use the same information set and execution profile.
- Same-root observations are not independent samples.
- Holdout is never silently merged back into development data.
- Multiple-hypothesis discovery is explicitly controlled.
- Positive permission creation requires a stricter promotion gate than risk-reducing constraints.
- Production authority is versioned in the D4 promotion registry and can be suspended/retired with a traceable record.

## V20 initial state
D4 governance is live, but the shipped promotion registry contains **zero new positive permission-creation rules**. Therefore V20 initially behaves like the validated V19 D3 decision stack while collecting the evidence required for future selective promotion.

## Production chain
`D1 Truth → Fundamental → Narrative → Timing → D2 Sciences → D3 Causal Adjudication → D4 Registry/Governance Receipt → Final Permission → Execution → Immutable Outcome → Forward Calibration → Promotion/Reject/Retire`.

# Alpha Lab Temporal Clearance — V16.1 Routing

Input direction/core state comes from V16.1 Fundamental + Narrative Transmission logic. Timing never creates or flips direction.

## A. Resolve temporal identity
Resolve broker/expression/reference market, relevant venues, contract/option series when material, IANA timezones, DST, settlement/business calendars and holiday/half-day state.

## B. Classify each clock by decision materiality
- `DECISION_CRITICAL`: unresolved/unsafe state can change current Edge/permission.
- `MATERIAL_SECONDARY`: relevant to validity/confidence/review but cannot alone flip permission.
- `CONTEXTUAL`: record only.

Do not attempt exhaustive clock collection for its own sake. Retrieve the clocks capable of changing the current decision or its safe validity window.

## C. Dependency-aware graph
Collapse same-root clocks and separate informational, mechanical, liquidity and correlated effects. Calendar labels have no directional sign by themselves.

## D. Event/hazard adjudication
Fixed T-minus points are review anchors, not universal veto windows. A later event is not a veto by existence. Use adaptive hazard state and the actual execution time budget.

## E. Time-to-exploit and operational feasibility
Compare safe window with M1 Donchian duration telemetry when mature; otherwise use explicit qualitative safe margin. Subtract analysis/transport latency. `valid_until` must precede the earliest decision-critical hard hazard.

## F. Clearance
Return exactly one: `CLEAR`, `CLEAR_WITH_CONSTRAINTS`, `HOLD`, `VETO`, `UNDETERMINED_MATERIAL`, `CLOSED`.

- unresolved decision-critical clock that can flip permission -> HOLD/UNDETERMINED;
- secondary unresolved clock -> CLEAR_WITH_CONSTRAINTS / earlier review;
- contextual unknown -> no change;
- actual unsafe/hard event state -> VETO;
- no material obstacle -> CLEAR.

## G. Handoff
Only an already Active Core Candidate may become `EDGE_ACTIVE` under `CLEAR/CLEAR_WITH_CONSTRAINTS`. Timing cannot upgrade Bias/No-Edge/Relative Edge or create a new direction.

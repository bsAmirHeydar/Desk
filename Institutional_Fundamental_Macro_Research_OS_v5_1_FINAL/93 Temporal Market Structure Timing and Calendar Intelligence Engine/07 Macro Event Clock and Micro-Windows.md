# Macro Event Clock and Micro-Windows

For every material scheduled event store official source, exact local timestamp, timezone, UTC, expected release family, first-release/revision state, affected causal channels and schedule-version status.

Default adaptive checkpoints: `T-240, T-120, T-60, T-30, T-15, T-5, T0, T+5, T+15, T+30, T+60, T+240`. These are research checkpoints, not universal trade bans.

Event phases: `PRE_EVENT_NORMAL`, `POSITIONING`, `LIQUIDITY_WITHDRAWAL`, `RELEASE`, `FIRST_REACTION`, `CROSS_ASSET_CONFIRMATION`, `NARRATIVE_SELECTION`, `PERSISTENCE_TEST`, `CONSUMPTION_REASSESSMENT`.

Event proximity is classified as `VALIDITY_CONSTRAINT`, `TRUE_VETO`, or `NEXT_REVIEW_TRIGGER`.

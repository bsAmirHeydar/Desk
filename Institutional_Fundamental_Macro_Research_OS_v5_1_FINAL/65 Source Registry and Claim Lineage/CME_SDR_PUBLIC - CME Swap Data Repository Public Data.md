# CME SDR — Public Swap Transaction Data

## Official route
https://www.cmegroup.com/market-data/repository/data.html

## Access / cadence
PUBLIC_FREE

## Institutional use
Cleared, non-cleared and bilateral swap transactions reported to CME SDR across supported asset classes.

## Point-in-time / latency
Real-time/near-real-time after applicable mandated delays.

## Hard boundaries
- SDR print is a direct transaction fact, not identified client direction.
- Repository share is not the whole OTC market.

## Admission contract
Record publication/retrieval/reference times, exact table/file/product, units, corrections/cancellations where applicable, access class, and whether the observation is direct, aggregate, proxy or model inference. A registered source is not assumed available in a run.

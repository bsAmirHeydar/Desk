# Adversarial Institutional Analysis Capability Test

This test evaluates whether the canon can support institutional analysis under unfamiliar conditions. It is not a learning examination.

## Test classes

### Object definition failure

Provide an ambiguous market, company, country or event request. The analyst must resolve instrument, jurisdiction, timing, information set and horizon before synthesis.

### Competing-model failure

Provide evidence consistent with two rival explanations. The analyst must identify discriminating evidence rather than average the models.

### Horizon conflict

Create a structurally favorable state with an adverse event shock. The output must preserve both conclusions and estimate their relevant half-lives.

### Revision and hindsight trap

Provide a historical cutoff with later data revisions. The reconstruction must use the contemporaneous information set and quarantine ex-post facts.

### Cross-asset contradiction

Provide a primary-market move not confirmed by rates, FX, credit or physical evidence. The analyst must reduce confidence or explain the divergence.

### Portfolio hidden-driver test

Provide apparently diversified positions sharing one underlying fundamental driver. The analyst must identify concentration, nonlinear exposure and hedge failure.

### Unknowns test

Remove a critical data source. The analyst must produce an insufficient-evidence or bounded conclusion rather than fabricate precision.

## Pass standard

A passing output must satisfy [[79 Institutional Fundamental Analysis Output Architecture/15 Institutional Report Output Contract and Acceptance Gate]] and preserve all material contradictions and unknowns.

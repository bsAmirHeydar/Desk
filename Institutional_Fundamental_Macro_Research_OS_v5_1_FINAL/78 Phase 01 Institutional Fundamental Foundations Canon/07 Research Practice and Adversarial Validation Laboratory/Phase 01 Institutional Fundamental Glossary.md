# Phase 01 Institutional Fundamental Glossary

> [!abstract] Purpose
> Establish a controlled vocabulary for foundational institutional fundamental research. Definitions are concise entry points; the linked monographs contain mechanism, controversy and historical depth.

| Term | Canonical working definition |
|---|---|
| **Accounting identity** | A relationship true by construction; it constrains stories but does not by itself establish behavior or causality. |
| **Ambiguity** | Uncertainty about which probability model or distribution is appropriate. |
| **Base rate** | Frequency of an outcome within a defined reference class. |
| **Bayes factor** | Ratio of the marginal likelihood of evidence under two models. |
| **Calibration** | Agreement between stated probabilities and realized frequencies over comparable forecasts. |
| **Carry** | Expected contractual or mechanical accrual absent valuation change, default or disruption. |
| **Causal estimand** | The precise causal effect or distribution the research seeks to identify. |
| **Claim** | A proposition that can be supported, contradicted, bounded or left unresolved. |
| **Conditional probability** | Probability evaluated under a stated condition or information set. |
| **Confidence** | Calibrated support for a precise claim, distinct from certainty or conviction. |
| **Confounder** | A cause of both exposure and outcome that can bias causal interpretation. |
| **Constraint** | A legal, physical, accounting, liquidity, political or balance-sheet limit on feasible behavior. |
| **Contemporaneous expectation** | Belief or market-implied distribution available at the historical cutoff. |
| **Counterfactual** | Outcome that would have occurred under an alternative intervention or state. |
| **Credit risk premium** | Compensation for expected loss uncertainty, liquidity, covariance and tail exposure beyond expected default loss. |
| **Decision object** | Precisely defined question relevant to a mandate, such as exposure, hedge, valuation or monitoring. |
| **Density forecast** | Probability distribution over possible outcomes rather than one point. |
| **Discount rate** | Required expected return or stochastic discounting mechanism converting future payoffs into present value. |
| **Double counting** | Treating dependent evidence or repeated manifestations of one driver as independent confirmation. |
| **Endogeneity** | Dependence between an explanatory variable and unobserved determinants of the outcome. |
| **Event** | Precisely defined set of outcomes within a specified horizon. |
| **Evidence item** | Observation, estimate, document or identified result bearing on a claim. |
| **Expiry** | Date or information event after which a conclusion requires full re-underwriting. |
| **External validity** | Extent to which a result transports to other populations, countries, institutions or regimes. |
| **Factor** | Observed or latent common driver of multiple variables or payoffs. |
| **Falsifiability** | Possibility that specified evidence could count against a claim. |
| **Flow** | Quantity measured over an interval, such as income, lending or production. |
| **Fundamental driver** | Variable capable of changing cash flows, discount rates, scarcity, default, currency value or resilience through an explicit mechanism. |
| **Goodhart law** | A measure can lose informational value when it becomes a target or binding rule. |
| **Half-life** | Time required for an effect or information contribution to decay by half under a defined model. |
| **Identification** | Assumptions linking an unobserved estimand to observable evidence. |
| **Information set** | All admissible information available at a specified cutoff. |
| **Instrumental variable** | Variable used to isolate exogenous variation under relevance and exclusion assumptions. |
| **Invalidation** | Evidence that materially contradicts the mechanism or maintained assumptions. |
| **Latent state** | Unobserved condition inferred from noisy measurements. |
| **Likelihood** | Probability or density of observed evidence under a hypothesis or parameter. |
| **Locator** | Exact table, page, paragraph, series, release or timestamp supporting a claim. |
| **Lucas critique** | Behavioral relations may change when policy rules change. |
| **Mandate** | Authorized objective, benchmark, horizon, instruments and constraints. |
| **Margin of safety** | Difference between estimated value or resilience and the adverse threshold, acknowledging uncertainty. |
| **Market expectation** | Belief distribution embedded in surveys, curves, forecasts, contracts, positioning or behavior. |
| **Measurement error** | Difference between observed measure and the target construct. |
| **Mediator** | Variable transmitting part of a causal effect. |
| **Model card** | Structured record of purpose, assumptions, inputs, domain, limitations and failure history. |
| **Model risk** | Risk that specification, estimation, implementation or use produces misleading conclusions. |
| **Natural experiment** | Institutional or historical variation approximating a controlled comparison. |
| **Nominal quantity** | Measured in current currency units without removing price-level change. |
| **Nowcast** | Estimate of the current or very recent state before complete official data are available. |
| **Numeraire** | Unit in which value is expressed. |
| **Opportunity cost** | Value of the best feasible alternative forgone. |
| **Partial identification** | Evidence and assumptions bound a parameter without producing a unique point. |
| **Path dependence** | Outcome depends on sequence and history, not only current state. |
| **Payoff** | Cash flow, carry, recovery, scarcity service, hedge value or other benefit generated by an asset or contract. |
| **Persistence** | Extent to which a state or shock carries into future periods. |
| **Physical probability** | Real-world outcome probability, distinct from risk-neutral pricing probability. |
| **Point forecast** | Single numerical forecast, typically a conditional mean, median or mode. |
| **Posterior** | Belief distribution after updating with specified evidence. |
| **Posterior predictive** | Distribution of future or replicated observations integrating parameter uncertainty. |
| **Priced distribution** | Distribution or set of expectations inferred from prices under assumptions about risk premia and market structure. |
| **Prior** | Belief before incorporating specified evidence. |
| **Proper scoring rule** | Forecast score designed so truthful probability reporting is optimal. |
| **Provenance** | Origin, transformation and custody history of evidence. |
| **Real quantity** | Nominal quantity adjusted for a price index under stated convention. |
| **Reference class** | Set of cases used to establish an outside-view base rate. |
| **Reflexivity** | Feedback in which beliefs or prices alter behavior and fundamentals. |
| **Regime** | Configuration of state, policy, institutions and constraints with distinct relationships. |
| **Revision** | Change to a previously published data value or methodology. |
| **Risk** | Uncertainty represented by a sufficiently specified probability distribution. |
| **Risk-neutral probability** | Pricing distribution distorted by the stochastic discount factor; not directly a physical forecast. |
| **Risk premium** | Compensation for uncertainty, covariance, illiquidity, tail exposure or institutional constraints. |
| **Robust conclusion** | Conclusion that survives meaningful changes in assumptions or models. |
| **Scenario** | Internally coherent path of states, policies and feedbacks. |
| **Selection bias** | Distortion caused by nonrandom inclusion, observation or survival. |
| **Shadow value** | Marginal benefit of relaxing a binding constraint. |
| **Shock** | Innovation or intervention not predicted by the specified information set and model. |
| **Source hierarchy** | Ordering of sources by directness, authority, methodology and independence. |
| **State** | Distribution of economic, financial, institutional or physical conditions. |
| **Stock** | Quantity measured at a point in time, such as debt, wealth or inventory. |
| **Structural break** | Change in definitions, institutions or relationships that invalidates stable-parameter assumptions. |
| **Surprise** | Difference between released information and a contemporaneous expected distribution. |
| **Tail dependence** | Tendency of variables to experience joint extremes beyond ordinary correlation. |
| **Term premium** | Compensation and model residual associated with holding long-duration bonds rather than rolling expected short rates. |
| **Thesis** | Structured set of claims linking state, expectations, mechanism and conclusion. |
| **Transition risk** | Uncertainty about movement from one regime to another. |
| **Transmission channel** | Mechanism connecting a state or information change to payoffs or required returns. |
| **Treatment** | Intervention or exposure whose causal effect is being studied. |
| **Unknown ledger** | Record of material unresolved quantities, mechanisms and model omissions. |
| **Utility** | Representation of preferences over outcomes under stated assumptions. |
| **Valuation** | Price relative to a defined payoff, cash-flow, scarcity or replacement-value benchmark. |
| **Vintage** | Specific published version of a data observation or series. |

## Usage rules

1. A term must not silently change meaning across notes.
2. Every probability, state and conclusion must include horizon and information set.
3. Accounting, causal, predictive and valuation claims must remain distinct.
4. Terms such as risk premium, liquidity, regime and fundamentals require operational definitions in each application.
5. New domain-specific terms belong in later phase glossaries and must map back to this vocabulary.

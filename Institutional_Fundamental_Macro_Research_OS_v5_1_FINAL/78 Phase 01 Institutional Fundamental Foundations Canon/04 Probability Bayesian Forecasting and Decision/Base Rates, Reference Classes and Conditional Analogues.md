# Base Rates, Reference Classes and Conditional Analogues

> [!abstract] Canonical thesis
> A forecast should begin with an appropriate reference class and then adjust for case-specific evidence. Historical analogues are useful only when selected by mechanisms and institutional conditions rather than outcome resemblance.

## Analytical intuition

Before asking what makes this case special, ask what usually happens in comparable cases. But “comparable” must mean similar mechanisms—debt currency, banking structure, policy regime—not simply a similar chart or headline.

## Institutional definitions and distinctions

| Term or distinction | Precise meaning |
|---|---|
| Base rate | Outcome frequency in a defined reference class. |
| Reference class | Set of cases judged relevant under explicit inclusion rules. |
| Inside view | Case-specific narrative and detail. |
| Outside view | Statistical distribution across comparable cases. |
| Analogue | Historical case used to inform mechanism, range or scenario. |

## Mechanism map

1. Define the forecast event.
2. Choose a reference class using pre-specified institutional features.
3. Estimate base rate with uncertainty and survivorship controls.
4. Adjust for discriminating case evidence.
5. Use multiple analogues and document mismatches.
6. Avoid selecting analogues after the outcome path emerges.

## Formal structure and notation

### Posterior odds with base rate

$$
Posterior\ Odds=Base\ Rate\ Odds\times Evidence\ Likelihood\ Ratio
$$

Case-specific evidence should modify rather than silently replace the reference-class prior.

### Hierarchical pooling

$$
\theta_j\sim N(\mu,\tau^2),\qquad y_j\sim p(y\mid\theta_j)
$$

Partial pooling balances global base rates and case-specific evidence, with less shrinkage when a unit has strong data.

## Competing interpretations and adversarial synthesis

| View | What it explains | Where it can fail |
|---|---|---|
| Outside-view discipline | Reduces uniqueness bias and narrative overconfidence. | Reference classes can be too broad or historically obsolete. |
| Inside-view expertise | Captures institutional detail and emerging mechanisms. | Often overfits and underweights failure frequencies. |
| Mechanism-conditioned analogues | Combines base rates with causal similarity. | Similarity weighting is partly judgmental. |

## Historical and institutional cases

### Sovereign debt crises

Debt level alone is a poor reference class; currency denomination, reserve status, maturity, investor base and external balance matter.

### Inflation episodes

Historical analogues differ in wage institutions, energy dependence, fiscal policy, credibility and globalization.

- **Cyclical:** determine how the mechanism changes across expansion, slowdown, recession, recovery, inflation and disinflation; interrogate: Choose a reference class using pre-specified institutional features.
- **Tactical/multi-week:** identify which expectation, valuation or policy assumption is vulnerable; test: Estimate base rate with uncertainty and survivorship controls.

## Failure modes and red-team tests

- Choosing reference classes by desired conclusion.
- Ignoring failed or censored cases.
- Calling an episode unprecedented to avoid base rates.
- Averaging cases with opposite mechanisms.
- Treating historical frequency as immutable probability.

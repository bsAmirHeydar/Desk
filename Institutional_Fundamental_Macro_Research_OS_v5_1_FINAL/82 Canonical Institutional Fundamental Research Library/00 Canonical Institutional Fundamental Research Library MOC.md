## Retrieval doctrine

1. Resolve the object and cutoff.
2. Retrieve one direct canonical monograph.
3. Retrieve no more than six dependency monographs from the registry.
4. Retrieve exact source contracts and current/historical evidence.
5. Use supporting legacy notes only for a named specialist sub-question.
6. Record every retrieved file in the Reading Ledger.

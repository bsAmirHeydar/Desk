# V14.1 Release Notes

## Purpose
V14.1 integrates the previously external V14 live-analysis prompt and the finalized Alpha Lab live operating decisions into the Obsidian Vault without replacing V11–V13 science.

## Added
- Module 92: live Full-Vault adjudication, Edge taxonomy, execution permission, forward learning and product output.
- Six-market production profile: XAUUSD, NASDAQ100, SP500, DJIA, EURUSD, USDJPY.
- `EDGE_ACTIVE`, `EDGE_CONDITIONAL`, `EDGE_RELATIVE`, `BIAS_ONLY`, `NO_EDGE`, `EVENT_OR_FRAGMENTED`, `INSUFFICIENT_EVIDENCE`.
- Strict permission rule: only `EDGE_ACTIVE` may become BUY/SELL; all other states are NO_TRADE.
- Direct mechanical execution handoff: M1 Donchian-20, 4 ATR initial stop, candle-by-candle trail.
- Permission applies to new entries only; open trades remain under mechanical exit logic.
- Minimal fail-closed execution JSON.
- Mandatory `Why Not Active?` disclosure for every conditional Edge.
- Scheduled-event proximity distinction between a true veto and an expiry constraint; currently a forward-validation CANDIDATE.
- Immutable forward-state archive, prior-call review, learning ledger and hindsight firewall.
- Learning promotion path: OBSERVATION → CANDIDATE → VALIDATED → CANONICAL.
- Forward-first validation policy; historical reconstruction is secondary evidence for the full live brain, while mechanical execution remains directly backtestable.
- Premium Persian RTL HTML Intelligence Explorer product contract.
- Simple email body with no attachments.
- Manual `ران` / `ران تست رو اجرا کن` launcher and a single hourly scheduled workflow profile.

## Preserved authority
- V11 / Module 89: force, consumption, remaining pressure, fact persistence, reversal risk, fundamental asymmetry.
- V12 / Module 90: attention, narrative validity/dominance/persistence, reflexivity, ignored facts, transitions.
- V13 / Module 91: instrument identity, universal family routing, FX/commodity/index adaptation.
- V14.1 / Module 92: live operational synthesis, Edge, permission, forward learning, execution/product handoff.

## Important limitation
V14.1 creates a stronger operating and learning system; it does not claim calibrated win probabilities or a proven trading edge. Candidate learnings remain explicitly provisional until promoted through forward evidence.

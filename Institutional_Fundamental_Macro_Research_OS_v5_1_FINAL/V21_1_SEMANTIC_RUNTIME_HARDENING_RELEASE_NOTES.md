# Alpha Lab V21.1 — Semantic Integrity & Cognitive Runtime Hardening

V21.1 is deliberately **not** a new science layer. It closes high-value gaps discovered in the V21 audit while preserving flexibility and avoiding feature inflation.

## Changed
- semantic cross-field validator for instrument/cutoff/horizon/direction/ID consistency;
- explicit present-or-applicability contract for first-class cognitive states;
- structured D1-linked evidence references and monitorable trigger predicates;
- full cognitive state/telemetry retention for D4 learning;
- canonical Module 89 ownership of `SWING_2_8W`;
- scenario tree changed from forced 2–6 to **1–6 materially distinct paths**; calibrated probabilities require D4 calibration record;
- four-layer surprise semantics: data, economic, policy, asset;
- more expressive reaction functions, dimension-specific regimes and causal edges;
- root alias/state ontology for cross-asset reconciliation;
- topic-aware retrieval and evidenced dimension coverage;
- review scheduler ignores stale events; cognitive adjudicator no longer emits `NONE` as a review trigger;
- six asset cognitive books received concise discriminator rules only.

## Intentionally not added
No new trading strategy, no portfolio authority promotion, no probabilistic forecasting without calibration, no large analog/source-value infrastructure before Forward data justifies it.
